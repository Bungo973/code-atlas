# 截图清单

README 引用的图放这里。**统一用内置示例（点「看示例」）拍**，理由有三个：
分析的是本仓库自己的源码，任何人都能复现同样的画面；不泄露任何私有代码；
仓库变了图也跟着变，截图不会悄悄过期。

窗口统一 **1440 × 900**，深色，拍之前先按「适应窗口」。

| 文件名 | 拍什么 | 要点 |
|---|---|---|
| `overview.png` | 主视图全景 | 侧栏 + 画布 + 详情栏都在画面里，不要选中任何文件 |
| `impact.png` | 选中 `src/core/graph.ts`，层级选 **2 跳** | 蓝色扇形传播路径要清楚；详情栏能看到 `N 个文件受影响 / 全部 M` |
| `depth.png` | 同一个文件，层级切到 **全部** | 和上一张并排能看出分层的意义 |
| `symbols.png` | 打开「分析」面板 → 疑似死代码 | 「**疑似**」两个字要在画面里 |
| `network.png` | DevTools → Network，分析完成后 | 证明零网络请求。**必须包含请求数为 0 的那一栏** |

⚠️ `network.png` 是唯一**不能**用示例拍的：示例会下载自己的源码 chunk，
画面里就有请求了，说不清楚。这一张要用「打开目录」选一个本地仓库来拍。
